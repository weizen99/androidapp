使用 Digital Garden 插件是目前 Obsidian 社群中最受歡迎的免費發布方案。它能讓你的筆記看起來像一個專業的網站，支援雙向連結、圖譜、預覽浮窗，且完全不需要支付任何伺服器費用。 以下是詳盡的設定步驟： ### 第一階段：帳號準備與雲端部署 這部分的目的是建立一個「雲端空間」來存放並運行你的網站。 1. 註冊帳號： * 註冊一個 [GitHub](https://github.com/) 帳號（用於存放程式碼與筆記數據）。 * 註冊一個 [Vercel](https://vercel.com/) 帳號（建議直接用 GitHub 帳號登入，用於自動構建並發布網站）。 2. 部署範本： * 前往 Digital Garden 的 [官方範本庫 (GitHub Repo)](https://github.com/oleeskild/obsidian-digital-garden)。 * 在頁面中找到一個藍色的 「Deploy to Vercel」 按鈕，點擊它。 * Vercel 會引導你將該範本複製（Create Git Repository）到你的 GitHub 中，請為這個儲存庫取名（例如 `my-garden`）。 * 等待 Vercel 跑完部署（Deployment），成功後你會得到一個網址（例如 `my-garden.vercel.app`）。 --- ### 第二階段：取得 GitHub 存取金鑰 (Token) 為了讓 Obsidian 插件能把筆記「推」到 GitHub，你需要給它授權。 1. 登入 GitHub，前往 Settings -> Developer settings -> Personal access tokens -> Tokens (classic)。 2. 點擊 Generate new token (classic)。 3. Note 填入 `Obsidian-Garden`，Expiration 改為 `No expiration`（永不到期）。 4. 重要勾選：勾選 `repo`（包含所有子項目）。 5. 點擊最下方的 Generate token，複製這串代碼（離開頁面後就看不到了，請先記在記事本）。 --- ### 第三階段：設定 Obsidian 插件 現在回到你的 Obsidian 本機軟體中。 1. 安裝插件：設定 -> 社群插件 -> 瀏覽 -> 搜尋 「Digital Garden」 並安裝、啟用。 2. 填寫設定：進入 Digital Garden 插件設定頁面，填入以下資訊： * GitHub username: 你的 GitHub 帳號名稱。 * GitHub repo name: 你剛才在 Vercel 建立的儲存庫名稱（例如 `my-garden`）。 * GitHub token: 剛才複製的那串代碼。 * Base URL: Vercel 給你的網址（例如 `https://my-garden.vercel.app`）。 3. 其他設定：向下捲動，你可以勾選是否要顯示「反向連結 (Backlinks)」、「本地圖譜 (Local Graph)」或「搜尋框」。 --- ### 第四階段：發布你的第一篇筆記 Digital Garden 不會自動發布你所有的筆記，只有你標記的才會上傳。 1. 添加元數據 (YAML)： 在你要發布的筆記最頂端加上這段代碼：
yaml
    ---
    dg-publish: true
    dg-home: true  # 只有首頁需要這行，其他的筆記不用
    ---
2. 執行發布： * 點擊 Obsidian 左側邊欄出現的「小草/花園」圖示。 * 或者按下 `Ctrl/Cmd + P` 搜尋命令：`Digital Garden: Publish Single Note`。 * 點擊 Publish 之後，稍等約 1-2 分鐘（Vercel 需要時間重新編譯），你的網址就會更新內容了。 --- ### 進階技巧與注意事項 * 中文檔名問題：如果你的筆記檔名是中文，有時候 Vercel 編譯會報錯。建議在 YAML 中加入 `dg-permalink: "my-article-title"` 來指定網址路徑，或者確保檔名不要有特殊字元。 * 自訂樣式：你可以在插件設定中的 Appearance 挑選主題（支援許多 Obsidian 現成主題），也可以在 GitHub 倉庫中的 `src/site/styles/user/custom-style.scss` 寫自己的 CSS。 * 多設備同步：如果你在多台電腦用，只要 Token 設好，大家都可以往同一個 GitHub 倉庫推內容，實現協同發布。 * 完全免費：GitHub 和 Vercel 的免費額度對於個人筆記來說「極其巨大」，除非你的網站每天有幾萬人訪問，否則終身免費。 如果你希望網站網址更漂亮，也可以在 Vercel 中綁定你自己購買的頂級域名（Domain），這部分則需要額外付域名商的錢。
