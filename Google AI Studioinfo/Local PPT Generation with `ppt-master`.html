在 Windows 系統中，如果 MCP (filesystem) 因為權限問題被鎖定，通常是因為 Claude 桌面版、Node.js 或目標資料夾（`C:\ppt-master`）的權限等級不匹配。 你可以透過以下三個步驟來取得並賦予所需的 Admin（管理員）權限： --- ### 第一步：以管理員身分執行 Claude 桌面版 (最直接) 這是解決「權限不足」最有效的方法，讓 Claude 有權啟動 `npx` 並讀寫磁碟。 1. 完全關閉 Claude：務必到右下角系統匣對 Claude 圖示點右鍵 -> Quit Claude。 2. 找到快捷方式：在桌面或開始功能表找到 Claude。 3. 管理員執行：對圖示點擊 右鍵 -> 選擇 「以管理員身分執行」 (Run as Administrator)。 4. 確認權限：彈出 UAC 視窗時點擊「是」。 5. 檢查設定：進入 `Settings` -> `Developer`，看看原本灰色的按鈕是否變得可以點選。 > 進階提示： 如果你想每次都自動以管理員執行，請對圖示點右鍵 -> 內容 (Properties) -> 相容性 (Compatibility) -> 勾選 「以管理員身分執行此程式」。 --- ### 第二步：賦予資料夾完全控制權限 如果你的專案放在 `C:\` 根目錄，Windows 預設會保護該路徑。你需要手動開放權限給你的使用者帳號。 1. 打開檔案總管，在 `C:\ppt-master` 資料夾上點擊 右鍵 -> 內容 (Properties)。 2. 切換到 「安全性」 (Security) 分頁。 3. 點擊 「編輯」 (Edit)。 4. 在清單中找到 「Users」 或你的使用者名稱。 5. 在下方的權限列表中，勾選 「完全控制」 (Full control)。 6. 點擊「確定」並套用到所有子資料夾。 --- ### 第三步：修改 PowerShell 執行策略 (針對 npx/Node) 有時候權限問題來自於 Windows 禁止腳本執行（`npx` 本質上是腳本）。 1. 在開始功能表搜尋 PowerShell，對它點擊 右鍵 -> 「以管理員身分執行」。 2. 輸入以下指令並按 Enter：
powershell
    Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
3. 出現提示時輸入 `Y`。 --- ### 為什麼這能解決「灰色按鈕」問題？ 當 Claude 嘗試啟動 MCP 伺服器時，它會在背景執行 `npx`。如果沒有管理員權限： 1. Windows 可能會攔截 `npx` 的執行。 2. Claude 偵測到「啟動失敗」，為了防止錯誤，它會把 UI 介面鎖定（變成灰色），讓你無法點選「Needs approval」。 完成以上步驟後，請務必「重啟電腦」或「完全重啟 Claude」，然後再次嘗試點擊「小錘子」圖示。 #### 如果依然是灰色： 這極大機率是 CC Switch + Ollama (haiku) 的問題。請做一個簡單的實驗： * 在對話框上方，暫時把模型切換回官方的 Claude 3.5 Sonnet（如果你有額度）。 * 如果切換後按鈕立刻變亮，那就證明 本地模型不支援工具調用，導致介面被自動鎖死，這就不是權限問題，而是模型「大腦」不夠強的問題。
