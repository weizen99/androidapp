在 T-SQL 中，要將某一天的資料更新到另一天，最有效率且常用的方式是使用 `UPDATE...FROM` 語法進行自我連接 (Self-Join)。 假設您的資料表中除了日期之外，還有一個用來識別項目的欄位（例如 `股票代號` 或 `ID`），否則系統無法知道 0306 的哪一筆要對應到 0309 的哪一筆。 以下是程式碼範例（假設關聯欄位名稱為 `代號`）： ### 程式碼實作
sql
UPDATE target
SET 
    target.k9 = source.k9,
    target.d9 = source.d9,
    target.週k9 = source.週k9,
    target.週d9 = source.週d9,
    target.月k9 = source.月k9,
    target.月d9 = source.月d9
FROM winnewdate AS target
INNER JOIN winnewdate AS source 
    ON target.代號 = source.代號  -- 請將「代號」改為您表中的實際關聯欄位（如：股票代號、ID）
WHERE 
    target.日期 = '20260309'     -- 目標日期
    AND source.日期 = '20260306'  -- 來源日期
    AND target.k9 IS NULL;       -- 選用：確保只更新目前是空值的資料
--- ### 重點說明： 1. 關聯欄位 (`ON target.代號 = source.代號`)： * 因為每天有約 1950 筆資料，您必須指定一個欄位來比對這兩天的資料（例如：股票代號）。 * 請務必將 `代號` 改為您資料表中實際的唯一識別欄位名稱。 2. 效能優化： * 1950 筆資料對於 SQL Server 來說是非常小的量，執行速度會非常快（不到 1 秒）。 * 建議在 `日期` 欄位與 `代號` 欄位上建立索引 (Index)，這會讓查詢更有效率。 3. 安全性建議： * 在正式執行前，您可以先將 `UPDATE` 改為 `SELECT` 來預覽結果，確保對應關係正確：
sql
        SELECT 
            t.日期 AS 目標日, t.代號, s.日期 AS 來源日, 
            s.k9, s.d9, s.週k9, s.週d9, s.月k9, s.月d9
        FROM winnewdate t
        JOIN winnewdate s ON t.代號 = s.代號
        WHERE t.日期 = '20260309' AND s.日期 = '20260306'
4. 處理空值： * 如果您希望不論目標欄位是否為空值都強制蓋掉，請刪除最後一行 `AND target.k9 IS NULL`。
