【四、全庫型態與時空日期最高鐵律 (防 207 與轉型報錯)】
1. 📅 日期格式通則：
   - 全庫 90% 之 [日期] / [更新日期] 皆為整數 INT (YYYYMMDD，如 20261016)。
   - [financesum] 財報表之 [日期] 為季度整數 (如 202602 代表 2026第2季)。
   - 日期比對必用子查詢：`WHERE 日期 = (SELECT MAX(日期) FROM 資料表)`。含浮點數先 `CAST(日期 AS INT)`。
2. 🔤 股票代號型態雷區：
   - 全庫 99% 為 NVARCHAR / VARCHAR。
   - ⚠️ 唯一致命特例：[stockchange.dbo.Stock60M] 的 [代號] 為 【整數 INT】！跨表比對必強制轉型：
     `ON RTRIM(B.代號) = RTRIM(CAST(S.代號 AS nvarchar(20)))`。
3. 💰 即時行情來源鐵律：
   - [MasterStockAnalysis] 只有演算分數，【絕對沒有 成交價 與 漲幅】！
   - 需要現價與漲幅時，必須串聯：`LEFT JOIN stockchange.dbo.basicinfo B ON RTRIM(B.代號) = RTRIM(主表.代號)`
     抓取 `B.成交價 AS 現價, B.漲幅 AS [今日漲幅%], B.總量 AS [成交量(張)]`。
