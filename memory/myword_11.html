關鍵避坑與底層架構鐵律 (避免歷史重演)】
1. 📊 SQL 欄位型態陷阱：
   - basicinfo 之最高與最低價欄位名稱為 [最高]、[最低]（絕對沒有「價」字！）。
   - basicinfo 數值多為 VARCHAR，比對必用 TRY_CAST(成交價 AS DECIMAL(10,2))。
   - WeeklyChipAudit 百分比欄位必加中括號 [特大戶變動%]，型態必用 DECIMAL(10,2) 防 8115 溢位。
   - Stock60M 之 [代號] 為 INT，跨表比對必強制轉型 CAST(代號 AS NVARCHAR)。

================================================================================
🚨 二十一項終極除錯防線條約 (V15.5 終極憲法)
================================================================================
1. 括號防護律：AS 欄位別名凡含 (%), (天), 中文, 符號或空格，100% 強制加上中括號 [別名]。
2. 無 CTE WITH 條約：WebMethod 與 ExecuteSQL 不支援 CTE WITH，前端範本全改用衍生子查詢 (SELECT ...) M。
3. 一字漲跌停防衛：(最高 - 最低) = 0 時，加 ISNULL(..., 0) 防 NULL 傳播。
4. Unicode N 前綴：所有中文文字比對 (如 LIKE N'%雙破共振%') 100% 加上 N 前綴。
5. 日期轉型防溢位律：資料庫日期帶有 .000000 浮點數時，必須先 CAST(日期 AS INT)，再進行 VARCHAR(8) 與 TRY_CONVERT。
6. 回測策略隔離律：嚴禁無差別 TRUNCATE！必用 DELETE ... WHERE 回測編號 = X；插入總表必開啟 SET IDENTITY_INSERT ... ON。
7. 視窗函數別名禁止律：嚴禁在同一層 SELECT 中將剛取的欄位別名直接用於後面的 OVER() 視窗函數。
8. Flutter 官方直通車律：Android 打包分身 App 僅改 applicationId，嚴禁修改 namespace；根絕 ClassNotFoundException 閃退。
9. Gemini 多金鑰防限額律：多金鑰輪詢池必須採用「不同 Google 帳號」輪詢；HTTP Header 帶上 "x-goog-api-key"。
10. Playwright 靜默穿透與防卡白屏律：守護腳本必須 headless=True；遇 Arkose Labs 驗證嚴禁自動化初次登入，必用原生 Chrome 登入 2FA 固化 Session；嚴禁攜帶 --no-sandbox 破壞安全沙盒。
11. 雙平台故障隔離：廣播推播時 Telegram 優先發送，Facebook 發文必須包覆獨立 try...except 與 clean_fb_profile_lock() 破鎖機制。
12. 真·回測頸線不破律：幾何 1:1 測幅之回測必須在頸線「上方」0%~3.5% (Close >= Neckline * 0.99)。
13. Flet 1.0 物件大寫與 RWD 防崩潰律：Border, Padding 必須大寫；子進程必須強制帶 -u 與 PYTHONUNBUFFERED=1；佈局必須採用 ResponsiveRow 防手機寬度溢出黑屏。
14. 母艦單一長輪詢與沙盒授權律：同一組 TG Bot Token 嚴禁同時運行多個腳本防 409 Conflict；母艦實施沙盒免密體驗與實戰密碼鎖 (2157) 雙軌制；連接埠衝突時執行 taskkill 瞬態釋放。
15. TradingView 工業版鎖定與繪圖純淨律：前端鎖定 lightweight-charts@4.2.1 穩定版；均線強制 priceLineVisible: false 根絕彩色橫向虛線；標記僅支援 arrowDown/circle。
16. 三屏聯動同源與事件捕獲穿透律：跨看板聯動必須同源 (同 Port 8888 或 44311)；穿透 DataTables 阻擋必用 addEventListener('click', handler, true) 於 Capture 階段攔截  代號。
17. Android Intent 穿透與 HTTPS 直連律：手機直通母艦嚴禁使用 intent:// 特殊協議 (防 ERR_UNKNOWN_URL_SCHEME)，必須採用標準 HTTPS 平滑跳轉；VBScript 隱形啟動之檔名與路徑絕對禁止使用中文！
18. 純英數代號正規清洗律與大寬表物理去重律：TG 機器人提取股號必須嚴格使用 re.search(r'([0-9]{4,6})', text) 防代號帶問號 Bug；大寬表必內建 ROW_NUMBER() ... dedup_rn = 1 物理防胞胎；動態乖離率結合股本規模標籤防賣飛飆股。
19. 大模型長文本防截斷與原廠 8K 解鎖律：
    * 調用 Google 原廠 API 必須強制宣告 maxOutputTokens: 8192，提示詞必注入「篇幅配速令」，確保雙表格與總監戰令 100% 完整收尾不被腰斬。
    * 必須建立「Google原廠 ➔ OpenRouter最新在線 ➔ 本地Ollama 7B」三重防禦裝甲，徹底消滅 404、429、503 與「全數繁忙」！
    * 總監一句話戰令必須嚴格落實四要素：【核心動作定性】+【具體數字生死價位】+【資金成數上限】+【一句克服人性的紀律】。
20. 顯式時段命令律 (Explicit Time-Mode Law - V15.5 NEW)：
    * 無頭瀏覽器 RPA 截圖嚴禁依賴伺服器時鐘盲猜交易時段！必須透過 `--mode live` 或 `--mode post` 顯式指令強制綁定特定 DOM 按鈕（`#btn_query_live` vs `#btn_query_post`），徹底杜絕非交易時段復盤誤判。
21. 私有網路存取穿透律 (PNA Chrome Armor Law - V15.5 NEW)：
    * 當公網或動態 DNS 網域（如 `duckdns:8888`）呼叫本地端私有服務（`127.0.0.1:5000`）時，Flask 必須於 `@app.after_request` 全域注入 `Access-Control-Allow-Private-Network: true` 與 `Access-Control-Allow-Origin: *`；前端優先採用 `http://127.0.0.1:5000` 直連，徹底消滅 Chrome 私有網路安全阻擋與家用路由器缺少 NAT Loopback 的黑洞！
