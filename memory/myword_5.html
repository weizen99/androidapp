📌 模組四：🚨 十二大終極除錯防線條約 (嚴禁重蹈覆轍！)
=======================================================
1. 括號防護律：AS 欄位別名凡含 (%), (天), 中文, 符號或空格，100% 強制加上中括號 [別名]。
2. 無 CTE WITH 條約：WebMethod 與中台 ExecuteSQL 不支援 CTE WITH，前端範本全改用衍生子查詢 (SELECT ...) M。
3. 一字漲跌停防衛：當 (最高 - 最低) = 0 時，OBV 按成交價與昨收比較賦值，加 ISNULL(..., 0) 防 NULL 傳播。
4. Unicode N 前綴：所有中文文字比對 (如 LIKE N'%雙破共振%') 100% 加上 N 前綴。
5. 日期轉型防溢位律：資料庫日期帶有 .000000 浮點數時，必須先 CAST(日期 AS INT)，再轉 VARCHAR(8) 與 TRY_CONVERT。
6. 1:1 去重防護：關聯 allcross_live 或 basicinfo 時，必須以 ROW_NUMBER() OVER (PARTITION BY 代號 ORDER BY 日期/自動編號 DESC) AS rn 鎖定 rn = 1，杜絕笛卡爾乘積膨脹！
7. Playwright 靜默防干擾：背景守護腳本一律採用 headless=True 與 channel="chrome"，嚴禁搶奪滑鼠焦點。
8. 雙平台故障隔離：廣播推播時 Telegram 優先發送，Facebook 發文獨立 try...except 與 clean_fb_profile_lock() 破鎖機制。
9. 跨網域 CORS 萬能放行：Flask 必須支援 @app.before_request 對 OPTIONS 預檢秒回 200，並允許 Access-Control-Allow-Headers: *。
10. 真·回測頸線不破律：幾何 1:1 測幅之回測必須在頸線「上方」0%~3.5% (Close >= Neckline * 0.99)，絕不將頸線下方蓄勢誤判為突破回測。
11. 🔴 T-SQL EXEC 參數禁止拼接律：EXEC 呼叫預存程序時，嚴禁在參數中使用 '+' 拼接字串（會觸發 102 語法錯誤），必須先宣告變數賦值後再傳入！
12. 🔴 前端 DataTables 單一結果集律：excelsql2.html 只讀取 DataSet 第一張表 (Table 0)。若需顯示統計合計，必須將統計摘要列與逐筆明細整合為單一結果集輸出！
