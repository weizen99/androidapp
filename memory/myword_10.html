【五、關鍵避坑與底層架構鐵律 (避免歷史重演)】
1. 📊 SQL 欄位型態陷阱：
   - basicinfo 之最高與最低價欄位名稱為 [最高]、[最低]（絕對沒有「價」字！）。
   - basicinfo 數值多為 VARCHAR，比對必用 TRY_CAST(成交價 AS DECIMAL(10,2))。
   - WeeklyChipAudit 百分比欄位必加中括號 [特大戶變動%]，型態必用 DECIMAL(10,2) 防 8115 溢位。
   - Stock60M 之 [代號] 為 INT，跨表比對必強制轉型 CAST(代號 AS NVARCHAR)。
2. 🤖 Telegram 409 Conflict 致命衝突防線：
   - 一個 Token 只能有一個進程連線！重啟或手動執行前，必須強制以真實 PID 斬首舊 bot：
     powershell: Get-CimInstance Win32_Process | Where-Object { $_.CommandLine -like '*zen_ai_bot*' } | ForEach-Object { taskkill /F /PID $_.ProcessId }
   - 嚴禁用模糊指令誤殺自己 PID 導致程式 0 輸出閃退。
3. 💻 硬體顯存物理之壁：
   - RTX 4060 (8G VRAM) 只能跑 ≤9B 模型（滿血 31 字/秒）；跑 27B/35B 必爆顯存落入 CPU 拖垮至 1~2 字/秒。
   - 大模型推理優先外包給 NVIDIA Build H100 API，零佔用本地硬體。
4. ⏰ Windows 批次檔編碼禁忌：
   - CP950 環境下，.bat 檔案嚴禁出現 Emoji (🚀/👑) 或特殊符號 (「/」/─)，避免觸發 0x7C 管道符崩潰。

【五、全庫型態與時空日期最高鐵律 (防 207 與轉型報錯)】
1. 📅 日期格式通則：
   - 全庫 90% 之 [日期] / [更新日期] 皆為整數 INT (YYYYMMDD，如 20261021)。
   - [financesum] 財報表之 [日期] 為季度整數 (如 202602 代表 2026第2季)。
   - 日期比對必用子查詢：`WHERE 日期 = (SELECT MAX(日期) FROM 資料表)`。含浮點數先 `CAST(日期 AS INT)`。
2. 🔤 股票代號型態雷區：
   - 全庫 99% 為 NVARCHAR / VARCHAR。
   - ⚠️ 唯一致命特例：[stockchange.dbo.Stock60M] 的 [代號] 為 【整數 INT】！跨表比對必強制轉型：
     `ON LTRIM(RTRIM(CAST(B.代號 AS nvarchar(20)))) = LTRIM(RTRIM(CAST(S.代號 AS nvarchar(20))))`。
3. 💰 即時行情來源鐵律：
   - [MasterStockAnalysis] 只有 `盤中現價`、`盤中總量`、`專家實戰總分`、`產業分類`，【絕對沒有 成交價 與 漲幅】！
   - 需要標準行情時，必須串聯：`LEFT JOIN stockchange.dbo.basicinfo B ON LTRIM(RTRIM(B.代號)) = LTRIM(RTRIM(主表.代號))`
     抓取 `B.成交價 AS 現價, B.漲幅 AS [今日漲幅%], B.總量 AS [成交量(張)], B.股本億 AS [股本(億)]`。
4. 🛡️ 笛卡兒積防爆與多對一鎖定：
   - `value` 每日評價表必帶 `AND V.日期 = (SELECT MAX(日期) FROM value)` (防 2500 倍膨脹)。
   - `financesum` 財報季表必用 `ROW_NUMBER() OVER(PARTITION BY 代號 ORDER BY 日期 DESC) AS rn ... rn=1` (取每檔最新一季)。
   - `allcross_live` 金叉數據必用 `ROW_NUMBER() OVER(PARTITION BY 代號 ORDER BY 日期 DESC) AS rn ... rn=1` (徹底消滅全 0 與 NULL)。
   - 一字漲跌停防衛：除法必用 `NULLIF(最高 - 最低, 0)`，收盤位置% 加 `ISNULL(..., 100.0)`。
   - 勝率百分比防呆：`CASE WHEN WinRate <= 1.0 THEN WinRate * 100.0 ELSE WinRate END` (防 5240% 膨脹)。
