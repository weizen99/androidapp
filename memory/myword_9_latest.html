📦 一、這三行指令的白話解析（Git 三步火箭）
Git 的運作原理就像把貨物打包寄快遞到 GitHub 雲端倉庫：
code
Code
[工作目錄 Working Dir]  ── git add ──>  [暫存包裝箱 Staging Area]  ── git commit ──>  [本機版本庫 Local Repo]  ── git push ──>  [GitHub 雲端倉庫]
 (您的電腦硬碟檔案)                       (挑選要寄送的檔案)                       (封箱打上版本標籤)                         (火箭發射抵達雲端)
git add README.md（挑選貨物放進箱子）：
告訴 Git：「把 README.md 這個檔案放進待發送清單（暫存區）」。
如果寫 git add .，就是「把目前資料夾內所有的變動檔案通通裝進箱子」。
git commit -m "docs: add comprehensive warroom README.md"（封箱並貼上出貨標籤）：
把剛剛箱子裡的檔案正式封存成一個不可抹滅的「歷史版本」。
-m "..." 是這個版本的備註日誌（Message），例如說明這次改了什麼，以後隨時能精準回溯。
git push origin main（快遞出車發射到雲端）：
把本機封存好的版本，正式推送到遠端伺服器（origin = 您的 GitHub 網址，main = 主要分支）。
執行完畢後，GitHub 網頁與 GitHub Pages 就會立即更新！

💡 三、量化總監必備的五大實用 Git 操盤技巧
技巧 1：【照妖鏡】推送前隨時看一眼改了什麼
在執行 commit 之前，在 CMD 輸入：
code
Cmd
git status
紅色檔名：代表您改動了、但還沒 add（還沒放進箱子）。
綠色檔名：代表已經 add，準備要 commit 封箱。
👉 這招能一眼看出有沒有不小心把私人檔案或奇怪的暫存檔打包進去！
技巧 2：【防爆盾牌】建立 .gitignore 徹底避開大檔案與金鑰阻擋
今天長官在 push 時，遇到 5.html (60MB) 大檔案警告以及 .vs 暫存檔，這就是因為沒有過濾！
只要在 C:\inetpub\wwwroot\androidapp\ 建立一個純文字檔名為 .gitignore，寫入以下內容：
code
Text
# 忽略 Visual Studio 暫存垃圾
.vs/
*.vsidx
*.suo

# 忽略超過 50MB 的超大歷史檔案 (防 GitHub 拒收)
5.html
6.html

# 忽略照片快取
photos/*.jpg
👉 有了這份過濾盾牌，以後長官就算大膽執行 git add .，Git 也會自動跳過這些龐然大物，push 速度快 10 倍，且永遠不會觸發報錯！
技巧 3：【極速懶人包】做一個桌面「一鍵推播.bat」
長官以後連 CMD 都不用開！將這三行存成 C:\test_c\一鍵推送記憶庫.bat，丟在桌面：

平常改完 HTML，滑鼠雙擊點一下，3 秒自動飛上 GitHub！
技巧 4：【後悔藥】不小心加錯檔案怎麼撤回？
如果不小心 git add . 把不該加的檔案加進去了，但還沒 commit，只要一行就能退回：
code
Cmd
git restore --staged <檔案名稱>
技巧 5：【時光機】查看最近 5 次的更新歷史
想確認上次是幾月幾號推上去的：
code
Cmd

會清楚列出最近 5 次的 commit 序號與備註說明，一清二楚！
