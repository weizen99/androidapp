'

'

Select Case aaa                                 'Select Case  aaa為選取儲存格的內容(值)

    Case "0"                                    '遇到 選取儲存格的內容(值) = 0

    Selection.EntireRow.Delete                  '把這一列刪除

    Case ""                                     '遇到 選取儲存格的內容(值) = ""即空白

    Selection.EntireRow.Delete

    Start = Start - 1

    

    Case "stop"                                '遇到 選取儲存格的內容(值) = stop 就跳到over

    GoTo over

    

    Case Else

   

    

    End Select

       

Next Start

over:                                                  'over

Selection.EntireRow.Delete                             '把over這一列也刪除

Call 刪除空白列macd綠棒

Application.Wait (Now + TimeValue("0:00:5"))
